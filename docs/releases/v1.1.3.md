# NetMeter 1.1.3 preview

NetMeter puts live download and upload speeds in the macOS menu bar. The readout stays aligned as rates change, and you can choose up to three metrics. Settings includes separate font styles for download and upload, usage history, a 14-day chart, and CSV export.

[Explore NetMeter and see screenshots](https://sudhirkumar136.github.io/SpeedMeter/).

### Download

`NetMeter-1.1.3-macOS-unnotarized.zip` contains a universal macOS app for Apple silicon and Intel Macs running macOS 15 or later. Unzip it to get `NetMeter.app`.

**Preview build:** The app is ad hoc signed and is **not notarized**. macOS Gatekeeper may block opening a downloaded copy. A Developer ID certificate and Apple notarization are required for a normal public installer; they are not available for this build. If you want to run it now, build from source with the commands in the [README](https://github.com/Sudhirkumar136/SpeedMeter#build-and-install).

### Highlights

- Transparent, fixed-position menu bar speeds with configurable units, precision, and metric order
- Settings tabs for Font Style and Usage Statistics
- Local daily usage tracking, retention controls, 14-day chart, and CSV export
- Launch at Login, automatic interface selection, and sleep/wake handling
